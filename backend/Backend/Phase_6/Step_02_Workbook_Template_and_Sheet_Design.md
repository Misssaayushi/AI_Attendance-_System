# Step 02 - Workbook Template and Sheet Design

## Goal
Define consistent monthly workbook structure and sheet schema.

## Workbook Structure
- File pattern: `attendance_YYYY_MM.xlsx`
- Primary sheet: `Monthly_Attendance`
- Optional sheet: `Summary`
- Optional sheet: `Metadata`

## Fixed Columns
- Student ID
- Roll Number
- Student Name
- Department
- Course
- Year/Batch
- Semester
- Section

## Dynamic Columns
- Day-wise attendance columns (`01` to `28/29/30/31`)

## Output
A stable sheet contract for automation and downstream reporting.

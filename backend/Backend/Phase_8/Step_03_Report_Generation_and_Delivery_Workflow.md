# Step 03 - Report Generation and Delivery Workflow

## Goal
Define robust end-to-end workflow for daily/monthly/department report delivery.

## Workflow
Generate report (or resolve existing file)
-> Validate report metadata
-> Prepare email payload
-> Attach file
-> Send email
-> Record delivery status

## Report Types
- Daily attendance report
- Monthly attendance report
- Department-specific attendance report

## Output
Reliable delivery workflow ready for automation hooks.

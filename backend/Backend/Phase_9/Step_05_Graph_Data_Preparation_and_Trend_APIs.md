# Step 05 - Graph Data Preparation and Trend APIs

## Goal
Produce frontend-ready graph structures without frontend transformations.

## Graph Endpoints
- Weekly attendance trend
- Monthly attendance trend
- Department comparison trend

## Response Shape
- labels array (dates/day names/departments)
- data array (counts or percentages)
- optional metadata (range, filters)

## Output
Graph-ready API contracts for direct chart consumption.
